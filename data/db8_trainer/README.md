# DB8 Trainerdaten

DB8 enthält die Trainertypen des Spiels. Es werden weiterhin keine Einzeltrainer geführt, sondern zehn Trainertypen.

Trainertypen referenzieren bevorzugte und tolerierte Standardformationen aus DB5 und enthalten ab KF_0.15.1 bevorzugte Taktikbereiche für die Regler im Taktikmenü.
