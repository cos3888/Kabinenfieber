# DB7 Spielsimulation

DB7 enthält die fachliche Grundlage für die Matchsimulation in Kabinenfieber.

Rolle von DB7:
- Matchkontext aus dem Spielstand vorbereiten
- einfache Simulationslogik bereitstellen
- Matchereignisse, Spielerbeteiligungen und Berichtsdaten erzeugen
- fertiges Matchergebnis an DB6 zur dauerhaften Historisierung übergeben

DB7 ist **nicht** die dauerhafte Ergebniswahrheit. Diese bleibt in DB6.
